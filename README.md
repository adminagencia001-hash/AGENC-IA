# AGENC-IA — Familylearning-NGW

Application de gestion des connaissances familial.

## Objectif
Centraliser, organiser et transmettre les connaissances de la famille (documents, souvenirs, savoir-faire, apprentissages) dans un espace partagé et simple à utiliser.

## Structure du dépôt
| Dossier | Contenu |
|---|---|
| `docs/` | Vision, besoins, architecture, feuille de route |
| `src/` | Code de l'application |
| `tests/` | Tests automatisés |
| `data/` | Données d'exemple (aucune donnée personnelle réelle) |
